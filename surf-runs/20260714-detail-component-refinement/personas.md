# Personas — detail campaign (8, in 4 reviewer sets)

Set A
1. Marisol, 34, ER nurse on nights. Logs meals in 20-second bursts on an iPhone SE
   (320px). Impatient; taps anything that looks tappable; hates wrapped buttons.
2. Dan, 58, pre-diabetic, low tech confidence, reading glasses. Struggles with faint
   grey text and icon-only buttons; needs units on every number.

Set B
3. Priya, 27, marathon-training analyst. Data-literate; cross-checks macro colors
   between dashboard, log, and progress; notices when the same metric changes color.
4. Theo, 41, blind in one eye, uses large text + keyboard nav on iPad. Cares about
   focus visibility, aria states, and contrast.

Set C
5. Jess, 30, new mom, one-handed phone use while feeding. Thumb-reach taps, relies
   on the bottom nav; confused when the active tab isn't obvious.
6. Marcus, 22, college lifter. Skims; reads only numbers and buttons; expects
   protein to look the same everywhere; will tap every chevron.

Set D
7. Elena, 47, meal-prep planner. Lives in recipes/meal-plan/grocery; checks items
   off in the store with spotty attention; needs check/delete affordances obvious.
8. Sam, 36, product designer trying the app out of curiosity. Judges border/shadow
   consistency, radius families, disabled states, and empty states harshly.
