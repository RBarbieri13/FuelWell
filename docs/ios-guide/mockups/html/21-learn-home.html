Mockup notes · Step 4

Categories carousel
132pt cards in a horizontal scroll. Each card carries a category-tinted 36pt icon, name in Inter 700 13.5pt, and a count "12 articles." A subtle radial-gradient tint in the top-right corner of each card uses the category color at low alpha — nutrition green, macros green, eating-out warm-amber, recovery purple.
Continue reading
Single white row with a 56pt thumbnail, eyebrow "CONTINUE READING," title, then a gradient-brand progress bar with the percent. Renders only if the user has an article in progress.
For-you hero · V2
Replaces the carousel as the first surface when the engine has a strong recommendation. Dark elevated card with the brand-green pulse + "FOR YOU TODAY" eyebrow, the article title in Outfit 700 19pt, and a "Why" strap explaining the engine's reasoning. Trailing gradient-brand "Read · 3 min" pill.
Featured list
72pt thumbnail with a corner category pill on a saturated brand-tinted gradient, then title (2-line clamp), one-line summary, meta row (X min · category · optional engine-fit chip). Each thumb uses its category color for instant scanning.
Search active · V3
Tall focused search field with caret. Below: category chips for narrowing the scope, then matched articles with substring highlighted yellow. "Suggested by Coach" tail surfaces an article that didn't match the query but the engine thinks is more useful for today's macros.
