Mockup notes · Step 4

Hero illustration · V1
Five fanned-out day-cards floating in a soft brand-tinted gradient — each card carries a day-of-week label and three macro-color dots representing the planned meals. The little gradient-brand sparkle in the corner telegraphs the AI generation. CSS-only, ChatGPT Images 2.0 swap-in is optional.
Form controls
Three sections inside one card: Days (stepper, default 5, range 1–7) · Meals per day (chip cluster: Breakfast / Lunch / Dinner / Snacks — multi-select, defaults to all four) · Mode (3-card segmented: Fast ≤25min / Balanced / Big-batch). The stepper value uses bg.elevated so it reads like a verdict, not an input.
Generating · V2
180pt brand-gradient orb with concentric rings — the "engine cooking" surface. Headline "Mapping 3 plans for your week" with the gradient-text accent. Below: a 4-step progress card — Pulling your macros (done) · Filtering your sources (done) · Resolving for variety (active spinner) · Ranking by fit (pending). Engine takes 3–5 sec in practice.
Results · V3
Inputs echo as small pills at top (5 days · 4 meals · Fast). Three plan cards stack. Top card (highest fit %) carries the success border and a "TOP" badge inside the label row. Each plan: bold one-line summary ("Higher protein, lighter dinners"), fit % pill, detail row (avg kcal/meal · avg prep · grocery items), and a tri-color macro fit bar showing the protein/carbs/fat split. Primary "View plan" CTA + ⋯ more. Bottom of frame: Regenerate + Tweak inputs row.
