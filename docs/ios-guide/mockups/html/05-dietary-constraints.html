Mockup notes · Step 4

Progress dots
Five of nine filled — color.text.primary #0A0A0F for filled, color.text.disabled #C7CCD3 for empty. Same 44pt nav row as M03 / M04.
Title block
"Anything we should avoid?" in Outfit 700 26pt, -0.022em. Subtitle: "Optional — you can change this later." The "OPTIONAL" eyebrow caplet sits above the title in the muted track to reinforce that Skip is a first-class path, not a back-door.
Chip · default
Pill (radius.pill) on color.bg.surface, 1pt color.bg.border, elevation.1. Label is Inter 500 14pt at color.text.body, height 36pt, horizontal padding 14pt. Chips wrap across rows — every option is visible without horizontal scroll on the 393pt frame.
Chip · selected
Per spec — fill flips to color.bg.elevated #0F1117, label to color.text.onDark, weight to 600. A small 14pt × glyph appears on the right at 70% white to make the de-select target unambiguous. No green tint: selection here is a constraint, not a positive verdict.
Chip · add
Dashed 1pt outline at color.text.secondary, transparent fill, no shadow. "+" leads the label. Tapping opens an inline text input that appends a custom chip to the row in the same selected style.
Free text · "Anything else?"
Multiline field, white surface, 1pt border, radius.md, three lines of breathing room (~92pt minimum). Placeholder: "e.g. no red meat after 8pm, low FODMAP, halal" at color.text.muted. Focused state (V2) bumps the border to color.text.primary with a 3pt soft halo and the caret blinks at the insertion point. Helper text below reminds users this goes to the plan engine verbatim.
Continue · always enabled
This screen is optional — Continue is never disabled. V1 shows the "dim" state (color.text.primary @ 88% opacity, no halo) — full affordance, low gravity, because no selections were made. V3 shows the "enabled" state — gradient.brand + elevation.cta — because the user has expressed constraints worth committing.
Skip for now
Text link in color.text.secondary directly under the CTA, Inter 500 14pt. Continues to 3.6 Lifestyle with no constraints recorded. The plan engine treats Skip as "no known restrictions" and ranks everything.
iOS keyboard (V2)
Standard QWERTY at #D1D4DB tray with predictive-text strip showing "no red meat" highlighted. CTA dock hides behind the keyboard while focus is on the free-text field — Return commits and the dock re-emerges.
