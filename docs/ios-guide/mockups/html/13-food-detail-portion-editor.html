Mockup notes · Step 4

Hero — image + headline
116pt square photo placeholder left (warm gradient with food blobs — ChatGPT Images 2.0 at finalization). Right column carries the food title in Outfit 700 19pt, a brand · source line with a tinted source pill ("Rest." / "Recipe" / "USDA"), and the live calorie hero in DM Sans 700 40pt with a small green delta-chip ("+220 vs. plan slot").
Macro tiles
3-cell grid below the hero. Each tile a 12pt-radius white card with a 3pt top accent stripe in the macro token color, label / value / "of plan" line. All three numbers and the calorie hero re-render live as the portion changes — the central proof point of the editor.
Portion stepper
56pt minus/plus pill-corners flanking a dark value capsule with the current value in DM Sans 700 28pt + lowercase unit. Long-press the value to type a custom number. Below sits the unit segmented control (g / oz / serving) — switching unit re-scales the displayed value to the canonical-equivalent and rounds to the appropriate decimal.
Quick portions
Five-chip row (½, ¾, 1, 1¼, 1½) at radius.pill. Active chip flips to bg.elevated. Quick-pick is the muscle-memory shortcut for users who don't want to tap the stepper four times.
Meal slot + time
Two-column row of pickers: meal slot (Breakfast / Lunch / Snacks / Dinner) and time. Slot defaults to whichever section is currently empty in the day — engine's best guess. Time defaults to "Now."
Notes
Single multiline field, white surface, placeholder "Anything to remember? (e.g. 'no dressing', 'shared half')." Free text is appended to the log entry and surfaced in 3.11 meta line.
Diff strap · V2
When the user moves the stepper away from the source's default (1 serving), an amber strap appears between hero and macros: "Logging 1.5× the default — calories +366, protein +27g." Live-recomputes; tap to undo.
Delete row · V3
Renders only in edit-existing mode (entered by tapping a meal row in 3.11). Red label + trash glyph, bottom of the sheet. Tap → confirmation actionsheet.
