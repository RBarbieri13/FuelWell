Dashboard entry · V1
Top: inverted-row context strap carries the user's remaining-macros for the day in color.bg.elevated — "714 kcal + a 32 g protein gap left" with the three macro fingerprints beneath. The headline phrase picks up a green→blue gradient-text accent. Section below: "Top 3 for right now," three pick cards in priority order. Card #1 carries a Top Pick rank badge in gradient.brand; the others use a neutral inverted badge. Each card shows the restaurant logo tile (color-coded), the item the engine recommends, kcal + P/C/F at full saturation, and a one-line "Why this fits" with the fit reason highlighted in success-green.
Log-tab browse · V2
Same screen entered from the Log tab → Restaurants shortcut. Search field + "Show nearby" toggle (off by default — location prompt only on toggle). Featured horizontal carousel of curated cards with a tinted top-image and a small logo tile that drops 14pt below to overlap the image edge. Below: full alphabetical list with a 38pt logo tile, name, cuisine · distance, trailing macro-fit pill (green if it slots in the remaining-macros budget, amber if it's a stretch).
Search active · V3
User typed "chi". Search field focused (dark hairline + soft halo). Caret blinking. Cancel link right. The list collapses to substring-matched results with yellow-highlighted bold match. Cuisine chips above the results stay sticky so the user can narrow by category mid-search.
Coach nudge (V1)
Bottom-floating purple-avatar nudge above the tab bar reminding the user that the picks update live: "Updates as you log. Pick something and I'll re-rank the rest."
Macro-fit pill
The single most-important visual on this screen — a quick at-a-glance "this slots in" indicator. Green pill = within remaining budget for all three macros + calories. Amber pill = within calories but trips at least one macro. Pill carries the projected delta in DM Sans tabular.
