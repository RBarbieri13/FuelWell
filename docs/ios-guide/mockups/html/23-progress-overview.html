Mockup notes · Step 4

Range selector
Segmented Weekly / Monthly / 90-day / All. Defaults to Weekly per Max — daily noise discourages, weekly is where signal lives. Inactive options on the bg.borderSoft track; active flips to bg.elevated + 700.
Weight card · verdict-first
Eyebrow + "+ Add weight" pill on the right (gradient-brand when missing today's entry). Stat line first — DM Sans 700 32pt current value + a green/amber delta chip (−1.2 lb · WoW). Chart underneath as supporting data. 7-day SVG line chart with the current point dotted in success-green; today's data point gets a 3pt halo.
Macro adherence card
7-column stacked-bar chart by day. Each column shows the % adherence per macro stacked (protein-green / carbs-amber / fat-purple) with a top-of-bar miss segment in neutral. Percent number underneath each day in DM Sans tabular. Legend strip at the bottom carries weekly averages.
90-day view · V2
Range flipped to 90-day. Weight card chart becomes a denser line with a brand-green target zone shaded behind the actual trend. Stat shows total ("-3.8 lb · 90 days") + weekly average. Photo grid expands from a 3-tile this-week strip into a 4-column timeline of 8 progress photos with date labels. Measurements list appears beneath (waist / hips / chest with trend arrows).
Empty / V3
Range dimmed. Dark "WHY WEEKLY" promise card with the brand-green pulse, copy explaining the weekly-trend rule, and three entry actions (gradient-brand "Add weight" + ghost "Add photo" / "Log mood"). Below it: dimmed skeleton versions of the weight and adherence cards as placeholder shape — never reads broken, always reads "data coming."
