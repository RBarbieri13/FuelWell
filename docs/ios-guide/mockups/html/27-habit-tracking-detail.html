Mockup notes · Step 4

Top + range
Title + gradient-brand "+ Add habit" pill on the right. Range segmented control beneath: Week / Month / All. Defaults to Week — short range stays honest about variability.
Stat strap
Inverted band: "17 of 28 habit-days on track" + the 61% adherence number in DM Sans 700 brand-green. Same diagnostic-not-trophy tone as M26.
Dot grid · V1
Single 7×N grid card. Rows = habits, columns = days. Dot states: solid success-green (done), partial (50% green, ringed), empty white-with-dash (skipped today), white-bordered (no log), faint dashed (future). The grid is the visualization; it never gamifies.
Habit list
Tinted-icon row with habit name, plain-English definition ("≥7h actual sleep"), trailing weekly count (DM Sans tabular, "5 / 7"), and a today-toggle. Tapping the row promotes it into the expanded V3 state.
Grid-only · V2
Habit names move to 110pt row labels on the left of the grid; the separate list disappears. Best for 5–7 habits where the list duplicates the grid. Day headers run across the top of the grid column.
Expanded · V3
Sleep row expanded inline on a soft tinted background. 14-day strip in larger 4pt-radius squares (a more honest read than dots at the 2-week range). Stat pills beneath show 62% adherence, current streak, longest streak, plus an info pill explaining the engine's drift signal. Suggested-habits row appears below ("Stretch 5 min", "Daily walk after lunch") with dashed-border dotted-line styling and a gradient-brand + pill to add.
