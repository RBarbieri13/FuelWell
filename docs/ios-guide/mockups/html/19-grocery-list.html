Mockup notes · Step 4

Header
Back / Title / Share / ⋯. Title carries the source ("From Plan A — 5 days") and the inverted progress strap below shows mid-shop status with a 44pt brand-green ring + check count + source pill.
Filter chips
"All / To-buy / Got it / Pantry" — pivot the list by check state. Default lands on "All"; tapping "To-buy" hides checked items.
Category heads
Small-caps section headers with a 8pt color dot per category: Produce → success-green, Protein → error-red, Dairy → info-blue, Pantry → warning-amber, Other → text-secondary neutral. Count on the right shows N of M done (DM Sans tabular).
Item rows
Checkbox + name + sub-source line (recipe / plan that contributed it) + trailing qty. Tap a row anywhere → toggle done; done items strike through and drop to muted text. Long-press → quick-edit popover with delete / move category / change qty.
Add row
Dashed-border "+ Add item" row appears at the bottom of every populated category for quick custom additions.
Empty state · V2
Centered CSS basket illustration on a soft brand-tinted gradient. Headline "Nothing on your list yet." with a two-button stack (gradient-brand "Pull from this week's plan" + ghost "Build from scratch"). Below: quick-start chip listing prior grocery lists with item counts — one-tap restore. No tab bar — keeps focus on the action.
Collapsed · V3
Category headers render as tappable cards with the dot, name, "N of M done" count, and a chevron. Tap to expand inline. Best for long lists (>30 items) where the user wants to swipe section by section. The "Produce" section shows open state; the others stay closed.
Bottom bar
Sticky two-button bar: gradient-brand primary "Check out" (exports as text or sends to grocery app integration at Phase 2) + ghost "Share" (sends as iMessage / WhatsApp). On V3 it adds a "Bulk check" button for power users.
