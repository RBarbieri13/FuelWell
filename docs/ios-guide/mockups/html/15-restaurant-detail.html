Mockup notes · Step 4

Hero banner
180pt brand-tinted gradient (Sweetgreen's greens) with abstract food-shape blobs. Floating glass nav overlay with back, share, favorite. The restaurant identity card overlaps the banner by −56pt and carries the logo tile, name in Outfit 700 20pt, cuisine · distance · price meta, and a row of attribute badges (Open · 0.4 mi · Pickup · "Hi-protein" — the success badge is the coach's signal that this brand has strong macro-fit options).
Coach context strap
Inverted band above the picks. Purple coach avatar + "Showing items that fit your 714 kcal · 32g protein gap" with a live toggle. Toggling off shows the brand's full menu without macro-fit ranking.
Coach picks · V1
Horizontal carousel of 3-pick cards. Top pick carries a 1.5pt color.semantic.success border + green-tinted shadow + gradient-brand "Top pick" rank badge. Each card shows item name, modifier sub, kcal in DM Sans 700 26pt tabular, P/C/F line, "Why this fits" rationale, then a gradient-brand "Log it" CTA + ⋯ more button.
Picks expanded · V2
Tapping a pick (or a recommended menu row) replaces the carousel with the full-width expanded card. Four numeric cells across (kcal / P / C / F) in DM Sans 18pt above three success-tinted delta tiles showing exactly how the item slots into the remaining macros. The full why-this-fits paragraph reads three sentences. Primary "Log 1 to lunch" + ghost "Customize" actions.
Menu list
Categorized (Bowls / Salads / Plates / Sides / Drinks). Each row: item name (+ green RECOMMENDED tag for engine picks), macro fingerprint (DM Sans tabular), trailing kcal stack and a 28pt "+ Add" pill. Tap row → open Food Detail; tap + Add → optimistic-log with macro-fit delta.
Filter active · V3
"Fits my plan" chip flipped on (success-green filled). Menu collapses to only the items that slot into the remaining macros — non-fitting rows render dimmed beneath a "Hidden by filter" affordance. Coach context strap reads "Showing 6 of 24 menu items that fit." Saves the user from manually re-doing the math the engine already did.
