Mockup notes · M36 Help

Header · Help icon
Back chevron left, "Help" title centered, info-blue Help-center icon button on the right (clearer affordance than relying on the screen title alone). The right-side icon opens an in-context help tour from any sub-route.
Search · sectioned preview
Option A resolved. One search field "Search articles, settings, or ask a question" plus a preview dropdown directly beneath that sections matches into Articles (3), Settings (2), and a single Ask Coach row that converts the query into a coach chat. Lower visual noise than three parallel search surfaces; clearer intent split than a single undifferentiated result list.
Inline jump-to menu
Horizontal pill row above the article grid with high-value links: Onboarding, Macros 101, Health Score, Coach Chat tips. Active state inverts (dark surface, white text).
Featured article
One hero card. ChatGPT-Images-2.0-caption placeholder (cool gradient with the caption rule in the bottom-left). 3-min read pill, title, lead. "One thing to try today" takeaway lives in a slim base-tone block beneath the lead with a success-green accent bar — the article-end commitment surfaced up front.
Categories scroll
Seven horizontal tiles per spec: Nutrition basics · Macros explained · Eating out · Recovery · Training fundamentals · Sleep & energy · Mindset. Each carries a token-colored icon and an article count.
Continue reading
List of articles the user started but didn't finish. 42pt thumbnail + title + progress track (info-blue fill) + percent. Renders only when there is in-progress reading; collapses cleanly on a fresh install.
Quick settings
The three rows that drive ≥80% of settings traffic: Notifications, HealthKit, Account. Plus an "All settings →" link to the full Settings screen. Right-aligned value column shows current state (On · Connected · @jordan.c).
FAQ & Knowledge Base
Single list row, info-blue brain icon. Title "FAQ & Knowledge Base", sub-label "fuelwellhealth.com/help", trailing external-link mark "↗". Tap → external Safari to the public knowledge base.
Talk to coach (prominent)
Promoted to a full-width inverted dark card. Two stacked elements: a top row with the coach avatar + line "Have a question? Ask coach directly." / sub "Replies usually within seconds · 24/7", and beneath it a full-width gradient.brand CTA "Start a coach chat →". More visual weight than the prior text-style mini-card.
Send feedback
Text-link only, centered at the bottom — intentionally low-emphasis, signals it's the route of last resort.
Variations
V1 single featured card (spec primary). V2 a 2-up featured row + a "Latest" tile, useful when the editorial team has fresh content. V3 categories pulled above featured — for users who self-navigate by topic.
