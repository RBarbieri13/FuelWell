Mockup notes · Step 4

Apple Sign-In
Solid black #000, 48pt tall, radius.md 12px. White SF logo + "Continue with Apple" in San Francisco 600 17pt per Apple HIG. Sits above the "or" divider on every state — primacy locked from wireframe.
Continue button states
V1 disabled: dark secondary fill (color.text.primary background at 0.45 opacity) — communicates that the affordance exists but isn't active. V3 enabled: switches to gradient.brand with the elevation.cta green halo. Same 48pt height, same position — only the fill changes.
Field states
Default: 52pt tall, white surface, 1pt color.bg.border, radius.md, Inter 500 16pt. Focused (V2 password): border switches to color.semantic.info #00B4D8 with a 3pt 14%-alpha ring. Error (component spec): red border + red ring + 12pt error message below.
iOS keyboard
V2 shows the password field focused with the system QWERTY keyboard up. Status bar stays black-on-light per iOS. Title block compresses (subtitle drops) and the form sits above the keyboard — no overlap.
Voice
H1: "Welcome back to your numbers." — direct, specific, claims the brand frame. Subtitle: "Sign in to pick up where your last log left off — or create a new account if you're fresh." No banned vocabulary.
Type stack
H1 in Outfit 700 28pt -0.022em. Subtitle in Inter 400 15pt. Field input in Inter 500 16pt. Continue + Forgot in Inter 17/14pt. Apple button stays on the system font per Apple HIG.
Forgot password
Inter 500 14pt, color.text.secondary. The underline lives on the action word "Forgot password?" only, not the whole row. Sits 16pt below Continue on every state.
