Mockup notes · Step 4

Top bar
30pt purple coach avatar with the brand-green online pulse beneath. "Coach" name in Inter 700 13pt. Trailing "New" link starts a fresh thread (info-blue, no border — feels iMessage-native).
Bubbles
Coach left: white with 1pt hairline, 20pt rounding except a tightened bottom-left corner. User right: bg.elevated with white text, mirrored corner. Embedded cards live inside the coach bubble — the dark macro tile or the recipe-thumb chip.
Quick replies
3-chip row hanging beneath the avatar column (offset 34pt). Primary chip uses gradient.brand; secondaries are white with hairline. Disappears once one is chosen.
Composer
+ button (open camera / log a meal / pick from library), pill-shape field with mic glyph inside, gradient-brand send. Placeholder: "Ask me anything about today…" — the most important copy on the screen. Send disables to dim-dark until text is present.
Empty / first-session · V2
Personalized headline "Hi Jordan, how can I help?" with gradient-text accent. Context pill ("Friday · 3:42 PM · 714 kcal left"). 2×2 grid of seed-prompt cards (icon + one-line question, tinted-square icon), and a small "Try saying…" card with two example prompts in italic. No prior thread shown.
Voice mode · V3
Long-press mic → dark gradient overlay. 200pt orb pulses while listening, brand-green LISTENING label up top, live transcript in Outfit 700 24pt with the actively-streaming word highlighted brand-green. Audio waveform beneath. Bottom: keyboard switch, end-call (error-red), and speaker toggle.
