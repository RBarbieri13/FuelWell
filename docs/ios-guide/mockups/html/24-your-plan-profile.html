Mockup notes · Step 4

Profile head
56pt squircle avatar with the brand-green/blue gradient and the user's initials. Name + email + pills (Maintain · Moderate · 32 yr · Female). Trailing edit button opens the avatar editor.
Targets card
Calories renders as a full-width dark hero cell (Outfit-numeric 40pt) with the macro target grid beneath. Each cell has a 3pt top accent in its macro color, tappable to drill into the per-target editor. "Tap to edit" hint anchors muscle memory.
Why-this-plan row
Below the targets, a soft strap referencing the same rationale shown at the 3.9 reveal — "Anchored to 1g protein per pound · recalibrated 14 days ago · next auto-check Sun." Tap to expand the full assumption set.
Recalculate · weighty
Gradient-brand 52pt CTA with a refresh glyph. Visually the heaviest element on the screen. Tap fires the V3 confirm modal — Max's rule: never recalc without showing the diff first.
Settings list · V2
iOS settings-style grouped rows: Edit goal / Edit body / Dietary constraints / Lifestyle / HealthKit / Notifications, each with tinted square icon and a meta line that surfaces the current setting (DM Sans tabular for numerics). HealthKit shows "Connected" in success-green; Notifications shows "Quiet 10p–7a" muted.
Recalc confirm · V3
Centered modal on a 45% dim scrim. Warning-amber alert glyph in a tinted ring + "Recalculate your plan?" head + supporting copy explaining what's about to change. Diff block shows the projected delta per number (DM Sans tabular). Two-action stack: gradient-brand "Recalculate now" + ghost "Cancel." Confirmation kicks off the same engine animation we showed at 3.9.
