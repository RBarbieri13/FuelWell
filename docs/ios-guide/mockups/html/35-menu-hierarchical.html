Mockup notes · M35 Menu

Header & profile
Title "Menu" in display 700 22pt, close-X in the top-right (icon-button, light surface). Below it a 52pt avatar card on inverted bg.elevated — name, goal pill, and today's Health Score with a small delta arrow. Avatar is itself tappable → routes to Your Plan / Profile (M24).
Hierarchical categories
Locked to single-pane hierarchical-collapsed per D4. Eight categories — Snapshot, Tracking, Meals, Training, Coach, Settings, Help, About — render as a single grouped list of 16pt 700 category rows with a chevron. Tap any row to expand its children in-place (chevron rotates 90°, row background shifts to bg.base); tap again to collapse. No two-tier tile redesign. Tracking is shown expanded in this mockup to demonstrate the pattern. Row vertical padding tightened from 11px to 9px so all eight categories fit above the fold without scroll.
Icon palette
Token-bound: Health Score / Daily Recap on success green; I/O · My day on info blue; Habits / Mood / Photos on premium purple; Meals destinations split across success, warning, info, premium, orange; Training on orange and info; Settings / Help / About on neutral. The Sign-out row is the only destructive row — label in color.semantic.error.
Help row (top)
A dedicated Help row sits directly under the user profile header — info-blue circular icon, title "Help" + sub-line "FAQs, articles, ask coach", chevron. Tap → opens M36 Help directly. Mirrors the Help category lower in the list (intentional duplicate for one-tap access from any session).
Coach · Settings · Help · About
Same category-row treatment as Tools sub-categories. Coach expands to one child (Coach Chat); Settings expands to Account, Permissions, Notifications, Data export, Sign out (destructive); Help expands to Learn articles, Contact support, Send feedback; About expands to About FuelWell, Privacy, Terms, Share, Version.
Sticky behavior
The Profile block is sticky to the top of the sheet when the user scrolls. The close-X stays in the safe-area top. Tab bar does not render here — the Menu is modal.
