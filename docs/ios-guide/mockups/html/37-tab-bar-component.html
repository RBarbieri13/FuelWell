Mockup notes · M37 tab bar lock

Geometry
88pt tall standard iOS tab bar with a 30pt home-indicator safe-area inset at the bottom. Five equal columns. Coach column is the same width as the others — the visual prominence is achieved by lifting the icon, not by stretching the cell. Coach icon container is 54pt and rises 22pt above the row baseline so the bottom of the container still tucks behind the bar's blur surface.
V2 locked · Raised circle (FAB-style)
D6 resolution: V2 is canonical, V1 (speech-bubble) dropped. 54pt circle. Default fill is gradient.brand with a softened green halo (A12 — inactive elevation toned down vs. the Round-2 draft). Active state keeps the gradient and adds a 4pt translucent green ring as the focus indicator. Inactive baseline variant drops to dark #0F1117 with a softer shadow (used during onboarding splashes / transitions).
Outer tabs (Home · Progress)
SF symbol line glyphs: house · chart.line.uptrend.xyaxis. Fill switches to house.fill / chart.bar.fill when active. Label color is text.muted when inactive, text.primary when active.
Second-tier tabs (Meals · Exercise)
Sit immediately left/right of Coach. SF symbols: fork.knife · figure.run. Same color/fill rules as the outer tabs. They borrow no visual prominence from Coach — the spacing alone signals their proximity to the centerpiece.
States rendered
Top to bottom: State 01 Home active (default app launch). State 02 Coach active — the centerpiece lights up. State 03 Exercise active — second-tier tab. State 04 Inactive baseline — no tab is "active" (splash / route transition). Coach retains its distinct shading across all four states.
Specs
Bar height — 88pt (incl. 30pt safe inset) Coach icon container — 54pt Coach lift above row — 22pt Coach corner radius — 50% (V2 locked) Standard tab glyph — 26pt bounding box Label type — Inter 600 · 10pt · +0.02em Active text — color.text.primary Inactive text — color.text.muted
