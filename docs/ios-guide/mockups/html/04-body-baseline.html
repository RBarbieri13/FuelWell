Mockup notes · Step 4

Progress dots
Four of nine filled — color.text.primary #0A0A0F for filled, color.text.disabled #C7CCD3 for empty. Centered in the 44pt nav row with the back chevron left-aligned.
Title block
"Tell us about you." in Outfit 700 26pt, -0.022em. Subtitle: "Five quick numbers — we'll set your starting calories and macros from these." Specific, no banned vocabulary, sets expectations on input volume.
Segmented control
Per spec: inactive cells use color.bg.surface (white) on a color.bg.borderSoft track with a 1pt hairline; active cell switches to color.bg.elevated #0F1117 with color.text.onDark white text at Inter 600. Same control reused for unit selectors (ft/in vs cm, lb vs kg) and Sex (3-way). Track is radius.md; cells round to radius.sm inside.
Numeric chips
Height + Weight value entry sits in a 56pt picker-style chip: DM Sans 600 28pt with tabular figures + a Inter 500 13pt uppercase unit label. Dashed border in the empty state (placeholder visible), solid + elevation.1 when filled. Tapping the chip opens the wheel picker sheet (V2).
Wheel picker sheet
Bottom sheet at radius.lg 18pt top corners with a 36 × 5pt grabber, Cancel / Title / Done header row, then a 216pt dual-column wheel. Center row gets full-saturation text + the iOS hairline-bordered selection band; neighbors fall to color.text.muted and tilt via perspective transform. Done is in color.semantic.success green — only place green appears in the chrome.
Age field
Single 56pt field, opens the iOS numeric keyboard on tap. Empty placeholder reads "Age in years"; filled state shows the value in DM Sans 600 24pt with "years" right-aligned in color.text.secondary.
Activity rows
Four white cards, radius.md, 8pt gaps. Real copy from spec: Sedentary "Desk, little movement", Light "1–3x / wk", Moderate "3–5x / wk", Very active "6+x / wk". Selected state mirrors M03 — 1.5pt color.semantic.success border, 5% on-track tint, filled radio. No hierarchy collapse; all four rows present at all times.
Continue · two states
Disabled (V1): dark secondary fill (color.text.primary @ 0.42 opacity) — affordance present but inert. Enabled (V3): gradient.brand with the elevation.cta green halo. Same 48pt height, radius.md 12pt — only the fill and shadow change.
Scroll
Form scrolls inside the device frame; CTA dock stays pinned with a 28pt fade to bg.base so content doesn't butt flush into the button. V1 shows scroll position at top; V3 shows it lower so Activity selection + CTA are visible together.
