Mockup notes · M33 Meals tab landing

Header
Display 700 26pt "Meals & Nutrition" with a sub-line ("Fri · 3 of 4 meals logged"). Trailing + button uses gradient.brand — opens M12 Add Meal sheet.
Today's plate hero
Smaller version of the M29 dual ring (124pt) paired with three macro rows on the right. Ring shows cumulative kcal vs target, macros show remaining (target − consumed) so the user sees what's left rather than what's eaten — different lens from Dashboard. Tap → M30 Energy balance (same destination as Dashboard widget).
Today's meals
Same row pattern as M10/M28 — color-coded meal-type icon, name + meta line, trailing kcal. Pending slots render dashed with the coach's projected kcal. V1 & V2 use the vertical list. V3 shows meals as a horizontal card row so the rest of the screen breathes.
Quick access · destinations
Six per spec: Meal Log, Restaurant Guidance, Recipe Browser, Meal Plan Generator, Grocery List, Macro History. Color tokens follow each destination's role — green (food), warning-amber (restaurants), info-blue (recipes), premium-purple (plan), orange (grocery), info-blue (charts).
Recent foods
Horizontal scroll of 132pt cards: meal-type-tinted placeholder image, name, kcal+macro chip. Tap → re-logs the same meal at "now" (M13 portion editor open).
Empty state
Hero swaps to coach-voice: No meals yet today. The fastest way is a photo — try the + above. Or coach can suggest something that fits your remaining macros. Two CTAs: Photo log (primary, opens camera) and Coach suggest (ghost). Today's meals collapses to dashed slots for breakfast/lunch/dinner. Recent foods still renders (last-week leftovers).
